# Esraniki

## Requirements

- Node.js >=18

## Setup

1. Clone repository:
```powershell
git clone https://github.com/rezelyn/Esraniki.git
```

2. Install dependencies:

```powershell
npm install
```
2. Setup environement variables:

```env
TOKEN=<your_app_token>
CLIENT_ID=<your_app_id>
```

3. Run the bot:

```powershell
npm start
```
