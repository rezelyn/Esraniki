# Esraniki

Esraniki is an open-source Discord bot orginaly made for my friends Discord server that provides couple of silly features.

## Requirements

- Node.js >=18

## Setup

1. Clone repository:
```powershell
git clone https://github.com/rezelyn/Esraniki.git
cd Esraniki
```

2. Install dependencies:
```powershell
npm install
```
3. Setup environement variables:
```env
TOKEN=<your_app_token>
CLIENT_ID=<your_app_id>
GUILD_ID=<dev_guild_id>
DEBUG=<true/false>
```

4. Run the bot:
```powershell
npm start
```
