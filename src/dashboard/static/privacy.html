Privacy Policy

Esraniki Privacy Policy

Last updated: August 2026

1. Overview

This Privacy Policy explains what information Esraniki collects, why, and how it's stored, when you use the Esraniki Discord bot or its web dashboard.

2. Information collected automatically

When you're active in a server that has Esraniki installed, it will mainly records your Discord user ID, avatar and username. It will also keep track of the count of the messages you send (not the message content itself), and the time you spend in voice channels. This data powers the statistics leaderboard and per-user statistics tracking and also some other features such as the social mini-games.

3. Dashboard login data

Logging into the dashboard uses Discord's OAuth2 flow. Esraniki receives your Discord user ID, username, avatar, and the list of servers where you have Administrator permission alongside Esraniki being installed, in order to show you the correct servers and profile information. A short-lived session token (valid for 24 hours) is issued and held in server memory, it is not written to disk. The Discord access token used to complete login is used briefly and is not stored after the login exchange completes.

4. Server configuration & data

Server administrators can configure many features such as server rules embeds, Twitch livestream announcements tracking, Minecraft server tracking, and channel server's listing selections. This configuration is stored in per-server ID storages and JSON files and used only to operate for the relevant feature.

5. What Esraniki doesn't collect

Esraniki does not store the content of your messages at all, only aggregate counts and checks the type of messages you send (text, image, video...). It does not use tracking cookies, third-party analytics, or advertising trackers. The dashboard stores your session token and selected server in your browser's local storage only, not in a cookie, she hate cookies, she prefers shrimps anyway!

6. How information is used

Collected information is used solely to operate Esraniki's features: statistics leaderboards, the dashboard, some of the social interactive mini-games, Twitch live announcements, and Minecraft server monitoring.

7. Data sharing

Esraniki shares data with third parties only as needed to operate its features: your server's configured Twitch channel names are sent to the Twitch API to check live status, and a configured Minecraft server address is sent to api.mcsrvstat.us to fetch server status. I do not sell or share your data with advertisers at all and will never do so.

8. Retention & deletion

Esraniki's per-server data are written and stored for as long as Esraniki remains in your server. Server administrators can edit or delete some of the data from the dashboard, removing Esraniki from your server does not automatically delete any existing data, as of now; if you wish to request full deletion of a server's data, please contact me at rezelxn@gmail.com, I'll do my best to accommodate your request.

9. Children's privacy

Esraniki is not directed at children under the minimum age required by Discord's Terms of Service in your region, and I do not knowingly collect data from users below that age.

10. Security

I take reasonable measures to protect stored data, but no method of storage or transmission is completely secure, and I cannot guarantee absolute security, if any sensitive data is involved in a security incident you'll be notified and I'll take appropriate action to protect any affected data.

11. Changes to this policy

This Privacy Policy may be updated periodically. Material changes will be reflected by updating the date above.

12. Contact

Questions about this Privacy Policy can be sent to rezelxn@gmail.com.
