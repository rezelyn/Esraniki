3. Open-source dependencies

Esraniki is built using a number of open-source projects. These projects remain the property of their respective authors and are used under their respective licenses.

    Core dependencies

  • discord.js - Node.js library for interacting with the Discord API.
  • @discord/embedded-app-sdk - Discord's SDK for building embedded Activities.
  • @discordjs/voice - Voice connection handling for discord.js.
  • dotenv - Loads environment variables from a .env file.
  • ffmpeg-static - Provides an ffmpeg binary for audio processing.
  • libsodium-wrappers - Encryption library used for Discord voice.
  • opusscript - Opus audio codec implementation.
  • youtube-dl-exec - Media download tooling (work in progress, not yet implemented as of v1.3.1).
  • colorette - Terminal color formatting used in logging.
  • Node.js - The JavaScript runtime Esraniki runs on.

    Dashboard and interface

  • Lucide Icons - The icon set used throughout the dashboard.
  • Catppuccin - The color palette the dashboard's themes are built on.
  • JetBrains Mono - The monospace typeface used across the interface.
  • Twemoji - The emoji artwork used for language flags.

The licenses and copyright notices applicable to these projects are available in their respective repositories and distributed license files. Where a dependency requires specific attribution, copyright notices, or license notices to be preserved, those requirements remain applicable to the relevant component.
